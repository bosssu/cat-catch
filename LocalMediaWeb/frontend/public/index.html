设置

与右上角一致：随机（默认）/ 相似 / 推荐 / 最新 / 已喜欢 / 搜索。搜索为虚拟模式，播放搜索结果时自动显示，不写入本机偏好。

默认关闭：服务端只推送不含「限制级」标签的内容。打开后才会推送带该标签的内容。

默认关闭：服务端不推送静态图。打开后 Feed / 搜索 / 网格才会出现 image 类型媒体。

带这些标签的内容不会出现在 Feed / 搜索 / 网格。可填多个。保存后立即生效。

默认关闭：Feed 右下角为留言。打开后切换为删除按钮（需确认）。

投到电视时由服务端执行：单个播放播完即停；单个循环在检测到电视播完后自动重推同一条。不向电视推送列表，也无「自动下一首」。
